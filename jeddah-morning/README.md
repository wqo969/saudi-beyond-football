# صباح جدة — JEDDAH MORNING

مجلة رقمية شخصية يومية باللغة العربية، بعدد صباحي وعدد مسائي، تُقرأ كمجلة ورقية فاخرة وتُثبَّت على الآيفون كتطبيق (PWA). خاصة ومحمية بكلمة مرور، وتعمل دون إنترنت، وبتكلفة صفر.

> **الحالة:** المرحلة الأولى — نسخة محلية للمراجعة. **غير منشورة** على أي خدمة خارجية. كل المحتوى الحالي **تجريبي** ومعلَّم بوضوح.

## التشغيل محليًا

```bash
cd jeddah-morning
npm install
npm run dev          # http://localhost:3000
```

في التطوير، إن لم تُضبط متغيرات الدخول تُستخدم كلمات مرور افتراضية مع تحذير في صفحة الدخول:

| الصلاحية | كلمة المرور الافتراضية (تطوير فقط) |
|---|---|
| قارئ | `demo-reader` |
| محرر | `demo-admin` |

للإعداد الحقيقي انسخ `.env.example` إلى `.env.local` واملأ القيم (انظر الملف).

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` / `build` / `start` | التطوير / البناء / التشغيل الإنتاجي |
| `npm run typecheck` | فحص الأنواع |
| `npm run lint` | ESLint |
| `npm test` | اختبارات الوحدات (Vitest) |
| `npm run test:e2e` | اختبارات طرف لطرف (Playwright، تحتاج `npm run build` أولًا) |
| `npm run check` | كل ما سبق عدا e2e |
| `npm run content:demo` | إعادة توليد الأعداد التجريبية |
| `npm run assets:icons` / `assets:demo-pdf` | توليد الأيقونات / ملف PDF التجريبي |

## الوظائف

- الصفحة الرئيسية وغلاف عدد اليوم مع التبديل بين الصباحي والمسائي.
- قارئ مجلة بتقليب صفحات ثلاثي الأبعاد حول الكعب الأيمن (اتجاه عربي)، بالسحب والأزرار ولوحة المفاتيح، مع استئناف القراءة.
- قارئ PDF (pdf.js) بالتكبير والتنقل.
- فهرس تفاعلي، أرشيف بتصفية حسب النوع والشهر، بحث عربي متسامح مع الهمزات والتشكيل.
- المفضلة (على الجهاز)، الوضع الليلي، القراءة دون إنترنت بحفظ العدد.
- غرفة تحرير: إنشاء وتحرير الأعداد والمقالات، نشر فوري أو مجدول، إلغاء نشر، حذف، استيراد JSON منظم وملفات PDF.
- بنية الإشعارات (Web Push) والنشر المجدول جاهزة وغير مفعّلة.
- الأقسام الثلاثة عشر: الطقس، الأخبار، كرة القدم، الموضة، ثقافة الكوير، الذكاء الاصطناعي، الفرص المهنية، الاقتصاد السعودي، التطوير الشخصي، أغنية اليوم، السينما والمسلسلات، اكتشاف اليوم، لغز اليوم.

## التثبيت على الآيفون (بعد النشر)

افتح الموقع في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## الضمانات التحريرية

- كل محتوى تجريبي يحمل `isDemo: true` ويظهر بشارة «تجريبي» وشريط تحذير.
- القوالب الإخبارية التجريبية لا تحوي أرقامًا أو أخبارًا؛ وهذا مفروض باختبار آلي.
- أي مقال حقيقي (غير تجريبي) في قسم يعتمد على بيانات حية **لا يُحفظ** دون مصدر.
- المحتوى المستورد يُحفظ مسودة افتراضيًا.
