# صباح جدة — JEDDAH MORNING

> **Your world. Your morning. Your magazine.** — نفس المجلة، لكن كل صباح تجربة جديدة.

مجلة رقمية شخصية يومية باللغة العربية، بعدد صباحي وعدد مسائي، تُقرأ كمجلة ورقية فاخرة وتُثبَّت على الآيفون كتطبيق (PWA). خاصة ومحمية بكلمة مرور، وتعمل دون إنترنت، وبتكلفة صفر.

> **الحالة:** P0–P10 مكتملة ومختبرة (PROGRESS.md). النشر: DEPLOY.md. الأعداد السبعة في المستودع **تجريبية**؛ الأعداد الحقيقية تُحفظ في التخزين الخاص فقط. ابدأ بـ CLAUDE.md.

## التشغيل محليًا

```bash
cd jeddah-morning
npm install
npm run dev          # http://localhost:3000
```

في التطوير، إن لم تُضبط متغيرات الدخول تُستخدم كلمات مرور افتراضية مع تحذير في صفحة الدخول:

| الصلاحية | كلمة المرور الافتراضية (تطوير فقط) |
|---|---|
| قارئ | `demo-reader` |
| محرر | `demo-admin` |

للإعداد الحقيقي انسخ `.env.example` إلى `.env.local` واملأ القيم (انظر الملف).

## الأوامر

| الأمر | الوظيفة |

## الوظائف
- **محرك تحريري ديناميكي:** كل عدد بغلاف ولوحة وتوزيع صفحات وترتيب مختلف، من مكتبة 27 قالبًا و15 لوحة، مع منع التكرار وتقرير جِدّة.
- **الإصدارات:** صباحي بشخصية اليوم (7 شخصيات أسبوعية)، مسائي JEDDAH AFTER DARK بهوية ليلية، و12 هوية للأعداد الخاصة.
- **القارئ:** تقليب ورق/انزلاق/بدون، صفحات أو عمودي، حجم نص، انتقال لصفحة، تركيز، استئناف، قراءة صوتية، مشاركة آمنة.
- **النسخ:** تفاعلية، مختصرة، مقال مستقل، PDF (قراءة واستيراد).
- **المكتبة الشخصية:** مفضلة، مجموعات، سجل قراءة، تقييمات، هدايا رقمية، تخصيص على الجهاز مع حصة اكتشاف.
- **غرفة التحرير:** مسار من 8 حالات، معاينة، تقرير الإخراج والذاكرة التحريرية، تجميد التصميم، استيراد JSON وPDF.
- **الخصوصية:** دخول إلزامي، noindex، PDF محمي، بيانات شخصية على الجهاز فقط مع تصدير وحذف.
- **دون إنترنت ووضع ليلي.**

## التثبيت على الآيفون (بعد النشر)

افتح الموقع في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## الضمانات التحريرية

- كل محتوى تجريبي يحمل `isDemo: true` ويظهر بشارة «تجريبي» وشريط تحذير.
- القوالب الإخبارية التجريبية لا تحوي أرقامًا أو أخبارًا؛ وهذا مفروض باختبار آلي.
- أي مقال حقيقي (غير تجريبي) في قسم يعتمد على بيانات حية **لا يُحفظ** دون مصدر.
- المحتوى المستورد يُحفظ مسودة افتراضيًا.
