# سياسة التكلفة — «صباح جدة»

**الميزانية: صفر ريال.** هذه السياسة ملزمة لكل مرحلة ولكل مساهم (بشريًا كان أو آليًا).

## القواعد

1. **لا API مدفوع** — ولا API «مجاني بحدود ثم يُحاسب تلقائيًا» إلا إذا كان الحساب بلا بطاقة دفع ويتوقف عند الحد بدل أن يحاسب.
2. **لا اشتراكات ولا ترقيات** — لا Vercel Pro، لا Supabase Pro، لا إضافات مدفوعة، لا نطاق مدفوع.
3. **لا بطاقة دفع** تُربط بأي حساب يخص المشروع.
4. **مكتبات مفتوحة المصدر فقط** (MIT / Apache-2.0 / BSD / OFL للخطوط).
5. **لا نماذج ذكاء اصطناعي بمقابل** داخل التطبيق. توليد المحتوى (إن وُجد) يتم خارج التطبيق ويُستورد ملفًا منظمًا.
6. أي إضافة جديدة لخدمة خارجية تتطلب: تسجيلها في الجدول أدناه، وذكر حد الخطة المجانية، وسلوكها عند تجاوز الحد.

## التحقق

- `package.json` لا يحتوي أي SDK لخدمة مدفوعة.
- لا مفاتيح API في المستودع؛ كل الأسرار في `.env.local` (مستثنى من git).
- المراجعة قبل كل مرحلة: هل أُضيفت خدمة؟ هل سُجّلت هنا؟

## التكلفة الفعلية حتى الآن
**0 ريال.** لم يُنشأ أي حساب أو مشروع أو اشتراك، ولم تُستخدم أي API. البحث عن حدود الخطط تم بأداة بحث الجلسة دون تكلفة على المالك.

اشتراك ChatGPT أو Claude لا يشمل استخدام الـ API مجانًا؛ لذلك لا يستدعي التطبيق أي نموذج ذكاء اصطناعي. أي توليد محتوى يتم خارج التطبيق ويُستورد ملفًا.
