# الأمان والخصوصية

## النموذج الحالي (محلي)
| الطبقة | التنفيذ |
|---|---|
| الوصول | `src/proxy.ts` يحجب كل المسارات والواجهات البرمجية دون جلسة؛ الاستثناءات: `/login`، `/offline`، manifest، `sw.js`، الأيقونات، `/brand`، أصول pdf.js العامة، `/api/cron` (سر مشترك) |
| الجلسة | كوكي `jm_session` موقّع HMAC-SHA256، httpOnly، SameSite=Lax، Secure في الإنتاج، 30 يومًا |
| الأدوار | قارئ / محرر؛ `/admin` و`/api/admin` للمحرر فقط، مع تحقق ثانٍ داخل كل إجراء خادم |
| كلمات المرور | مقارنة ثابتة الزمن عبر SHA-256؛ تأخير 600ms عند الخطأ؛ في الإنتاج يرفض الدخول إن لم تُضبط الأسرار أو كان السر أقصر من 32 حرفًا |
| إعادة التوجيه | `safeNext` يمنع إعادة التوجيه المفتوحة (`//`، `https://`، `/\`) |
| المعاينة | الأعداد غير المنشورة ترجع 404 للقارئ حتى لو عُرف الرابط؛ المحرر يراها مع شريط «معاينة» |
| PDF | يُخدم عبر `/api/pdf/[slug]` بعد التحقق من الجلسة والرؤية؛ الرفع يتحقق من توقيع `%PDF` لا من نوع الملف المعلن؛ حد 25MB؛ أسماء الملفات بنمط صارم |
| الفهرسة | `X-Robots-Tag: noindex`، `robots.txt` يمنع الكل، `X-Frame-Options: DENY`، `nosniff`، `Referrer-Policy`، `Permissions-Policy` |
| التخزين دون إنترنت | الخروج يمسح كاش الصفحات والأعداد المحفوظة؛ مسارات الدخول والإدارة لا تُخزَّن |
| الأسرار | `.env.local` فقط (مستثنى من git)؛ لا مفاتيح في الكود؛ مفتاح Supabase الخدمي لن يكون `NEXT_PUBLIC_` أبدًا |
| السجلات | لا تُسجَّل كلمات مرور أو رموز أو بيانات شخصية |
| البيانات الشخصية | على الجهاز فقط؛ تصدير وحذف من `/profile`؛ التخصيص قابل للتعطيل |
| المشاركة | الرابط المشارك يتطلب الدخول؛ لا روابط عامة |
| العزل | لا قراءة أو كتابة خارج مجلد المشروع؛ لا وصول لمشاريع Supabase القائمة |

## مخاطر معروفة ومعالجتها المخططة
| الخطر | الحالي | المخطط |
|---|---|---|
| تخمين كلمة المرور | تأخير بسيط | Supabase Auth (رابط سحري) + حد محاولات (P5) |
| كلمتا مرور مشتركتان | مناسب لمستخدم واحد | حسابات Supabase بأدوار (P5) |
| بيانات الجهاز غير مشفرة | localStorage | مزامنة اختيارية محمية بـ RLS (P6) |
| تبعيات | `npm audit`: 0 ثغرات | CI أسبوعي (P10) |

## النسخ الاحتياطي
