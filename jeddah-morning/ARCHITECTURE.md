# معمارية «صباح جدة» — JEDDAH MORNING

> وثيقة حية. آخر تحديث: المرحلة الأولى (نسخة محلية للمراجعة).

## 1. الفكرة في سطر

مجلة رقمية شخصية يومية بالعربية، بعددين (صباحي ومسائي)، تُقرأ كمجلة ورقية فاخرة على الآيفون (PWA)، خاصة ومحمية، وتعمل دون إنترنت، بتكلفة صفر.

## 2. المبادئ الحاكمة

| المبدأ | التطبيق |
|---|---|
| تكلفة صفر | لا API مدفوع، لا اشتراكات، خطط مجانية فقط (انظر `COST_POLICY.md`). |
| العزل | المشروع في مجلد مستقل `jeddah-morning/` بحزمه وقفل الاعتماديات وإعداداته وبيئته. لا يقرأ أو يكتب خارج مجلده. |
| الخصوصية | كل صفحة ومورد خلف بوابة دخول (`src/proxy.ts`) بجلسة موقّعة HMAC؛ `noindex` شامل؛ ملفات PDF تُخدم عبر مسار محمي لا من `public/`. |
| الصدق التحريري | لا أخبار أو بيانات حية مخترعة. كل محتوى تجريبي يحمل `isDemo: true` ويظهر بشارة «تجريبي» وشريط تحذير. |
| Mobile First و RTL | `<html dir="rtl" lang="ar">`، خصائص CSS منطقية، إيماءات تقليب بالاتجاه العربي. |
| مفتوح المصدر | كل الاعتماديات برخص MIT/Apache/OFL. |

## 6. نموذج المحتوى

```
Issue
  slug            "2026-11-26-morning"
  date            "2026-11-26"  (توقيت الرياض)
  edition         "morning" | "evening"
  number          رقم العدد
  title, coverHeadline, coverDek, coverSection
  status          "draft" | "scheduled" | "published"
  publishAt       ISO (للمجدول)
  isDemo          boolean  ← إلزامي الإظهار في الواجهة
  pdf             { file, pages? } اختياري
  articles[]      Article

Article
  id, section (أحد 13 قسمًا), kicker, title, dek, author
  readingMinutes, isDemo
  sources[]       { name, url }  ← مطلوب للمحتوى الحقيقي الإخباري
  body[]          كتل: p | h | quote | list | facts | puzzle | link
```

الأقسام الثلاثة عشر معرّفة في `src/lib/sections.ts`: الطقس، الأخبار، كرة القدم، الموضة، ثقافة الكوير، الذكاء الاصطناعي، الفرص المهنية، الاقتصاد السعودي، التطوير الشخصي، أغنية اليوم، السينما والمسلسلات، اكتشاف اليوم، لغز اليوم.

## 7. طبقة المحتوى (Repository)

`src/lib/content/repository.ts` يعرّف واجهة `ContentRepository` (قراءة/كتابة الأعداد وملفات PDF). التنفيذ يُختار بالمتغير `JM_CONTENT_BACKEND`:

- `local` (افتراضي): يقرأ ويكتب `content/issues/*.json`. الكتابة متاحة في التطوير المحلي فقط (نظام ملفات Vercel للقراءة فقط).
- `supabase` (المرحلة 2): Postgres عبر PostgREST بمفتاح الخدمة على الخادم فقط، وملفات PDF في Storage خاص بروابط موقّعة.

## 8. النشر المجدول

النشر المجدول **لا يحتاج أي خدمة**: العدد ذو الحالة `scheduled` يصبح مرئيًا تلقائيًا متى تجاوز الوقت `publishAt` (تُحسب الرؤية عند كل طلب في `src/lib/publishing.ts`). نقطة `/api/cron/publish` جاهزة لاحقًا لإعادة التحقق من الكاش أو إطلاق الإشعارات عبر Vercel Cron المجاني (مرة يوميًا في Hobby) أو GitHub Actions — غير مفعّلة الآن.

## 9. الإشعارات (بنية فقط)

- معالج `push` و`notificationclick` موجود في `sw.js`.
- `/api/push/subscribe` يرجع 503 ما لم يُضبط `JM_PUSH_ENABLED=true`.
- جدول `push_subscriptions` في المخطط.
- التفعيل لاحقًا عبر Web Push بمفاتيح VAPID مولّدة ذاتيًا (مجانية تمامًا، مدعومة على iOS 16.4+ للتطبيقات المثبتة).

## 10. المصادقة والحماية

- المرحلة 1: كلمتا مرور من متغيرات البيئة (`JM_READER_PASSWORD`، `JM_ADMIN_PASSWORD`) وجلسة `jm_session` موقّعة HMAC-SHA256 بـ `JM_SESSION_SECRET` (httpOnly، SameSite=Lax، Secure في الإنتاج، 30 يومًا).
- في التطوير فقط وعند غياب المتغيرات: كلمات مرور افتراضية مع تحذير ظاهر. في الإنتاج يرفض الدخول إن لم تُضبط.
- `proxy.ts` يحمي كل شيء عدا: `/login`، `/offline`، الأصول الثابتة، الأيقونات، `manifest.webmanifest`، `sw.js`.
- رؤوس أمان: `X-Robots-Tag: noindex`، `X-Frame-Options: DENY`، `Referrer-Policy`، `Permissions-Policy`، و`robots.txt` يمنع الكل.
- المرحلة 2: استبدال كلمات المرور بـ Supabase Auth (رابط سحري للبريد، مجاني) مع RLS.

## 11. القراءة دون إنترنت

`public/sw.js`:
- **التثبيت**: تخزين مسبق لصفحة `/offline` والأيقونات والـ manifest.
- **الأصول الثابتة** (`/_next/static`، الخطوط، الأيقونات): cache-first.
- **الصفحات**: network-first مع الرجوع للكاش ثم `/offline`.
- **حفظ عدد**: زر «احفظ للقراءة دون إنترنت» يرسل قائمة روابط العدد (الغلاف، القارئ، المقالات، PDF، فهرس البحث) ليخزّنها العامل في `jm-issues`.
- الخروج يمسح كاش الصفحات المحمية.

## 12. قارئ المجلة

مكوّن `FlipReader` بلا مكتبات: الصفحات = الغلاف، الفهرس، صفحة لكل مقال، الغلاف الخلفي. التقليب بتحويل CSS ثلاثي الأبعاد حول كعب المجلة (الحافة اليمنى، كما في المطبوعات العربية). الإيماءات: سحب من اليسار لليمين = الصفحة التالية؛ مفاتيح الأسهم معكوسة للعربية؛ مناطق نقر على الحواف؛ احترام `prefers-reduced-motion`. الموضع يُحفظ في `localStorage` ويُعكس في الرابط (`?p=`).
