# الأتمتة والإشعارات

## ما يعمل الآن دون أي خدمة
- **النشر المجدول:** العدد `scheduled` يصبح مرئيًا تلقائيًا عند `publishAt` (يُحسب عند كل طلب، توقيت Asia/Riyadh). المواعيد المعتادة: 07:30 صباحًا، 22:30 مساءً، 09:00 للخاص (زر «الموعد المعتاد» في المحرر).
- **منع النشر المزدوج:** «انشر الآن» على عدد منشور لا يفعل شيئًا (idempotent)، والنشر يجمّد التصميم مرة واحدة.
- **النشر اليدوي:** دائمًا متاح من لوحة الإدارة عند تعذر الأتمتة.
- **إشعارات داخل التطبيق:** `/notifications` تعرض الأعداد الصادرة منذ آخر زيارة.

## الجاهز وغير المفعّل
| العنصر | الملف | التفعيل (مجاني) |
|---|---|---|
| نقطة النشر المجدول | `/api/cron/publish` | ضبط `JM_CRON_SECRET` + Vercel Cron (يومي واحد لكل مهمة على Hobby، دقة ±59 دقيقة) أو GitHub Actions schedule |
| Web Push | `public/sw.js` (push/notificationclick)، `/api/push/subscribe`، `src/lib/notifications.ts` | مفاتيح VAPID مولّدة محليًا، `JM_PUSH_ENABLED=true`، جدول `jm_push_subscriptions` (iOS 16.4+ للتطبيق المثبت) |
| سجل العمليات وإعادة المحاولة | جدول `jm_publish_log` (فهرس فريد للنجاح) | P8: إعادة المحاولة 3 مرات بتباعد، تسجيل النجاح/الفشل |
| إيقاف الأتمتة | — | P8: مفتاح `JM_AUTOMATION_ENABLED` |
| CI | `ci/github-actions-ci.yml` | نسخه إلى `.github/workflows/` بعد الموافقة |

## أتمتة ChatGPT الحالية (موجز الصباح وموجز الليل)
**لم تُعدَّل ولم تُربط.** لا يوجد في هذه البيئة أي وصول إليها، ولم يُتحقق من وجود واجهة ربط. لا يدّعي المشروع أي تكامل معها.
الربط الممكن مستقبلًا دون تكلفة إضافية ودون تعديلها: أن تُصدِّر الأتمتة ملف JSON بصيغة `content/templates/issue.template.json`، ثم يُستورد يدويًا من `/admin/import` (يُحفظ مسودة ويمر بمراحل المراجعة). أي ربط آلي يتطلب التحقق من إمكانيته وموافقتك أولًا.
