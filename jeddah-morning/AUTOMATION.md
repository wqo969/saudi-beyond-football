# الأتمتة والنشر اليومي

## كيف يُنتَج العدد كل يوم (بالوسائل المجانية المتاحة)
لا يستدعي التطبيق أي نموذج ذكاء اصطناعي (لا API مدفوع). التحرير يتم في **جلسة Claude Code مجدولة** (ضمن اشتراكك الحالي، بلا تكلفة إضافية) أو يدويًا، ثم يُرسل العدد إلى التطبيق عبر واجهة خط الإنتاج المحمية.

```
جلسة مجدولة (06:40 و21:40 بتوقيت الرياض)
  └─ بحث في المصادر (WebSearch) → كتابة issue.json بصيغة القالب مع مصدر ورابط وتاريخ لكل خبر
  └─ node scripts/publish-issue.mjs --base <app> --file issue.json [--media dir]
        1. فحص ما قبل النشر (المخطط، المصادر، 13 قسمًا، 16–24 صفحة)      ← npm run issue:check
        2. منع التكرار مقابل ذاكرة 90 يومًا (/api/pipeline/memory)
        3. رفع الصور المرخصة (/api/pipeline/media)
        4. حفظ العدد مجدولًا 07:30 أو 22:30 (/api/pipeline/issue)
        5. إنتاج PDF من مسار الطباعة ورفعه (/api/pipeline/pdf)
        6. الإشعار يُرسل مرة واحدة عند الظهور (/api/pipeline/notify أو الفحص اليومي)
```

### البديل اليدوي (دائمًا متاح)
- **غرفة التحرير ← عدد جديد** أو **الاستيراد** (JSON أو Markdown) ← المسار: مسودة ← مراجعة ← تدقيق ← تصميم ← اعتماد ← مجدول/منشور.
- PDF: `node scripts/make-pdf.mjs --base <app> --slug <slug> --out x.pdf` ثم الاستيراد.

## ما يعمل تلقائيًا في التطبيق (مُنفّذ ومختبر)
| الوظيفة | التنفيذ |
|---|---|
| النشر المجدول بتوقيت الرياض | العدد `scheduled` يظهر عند `publishAt` (يُحسب عند كل طلب) |
| منع النشر المكرر | `publishIssue` idempotent؛ إعادة النشر لعدد منشور = «متجاهَل» في السجل |
| منع الاستبدال الصامت | خط الإنتاج يرفض استبدال عدد منشور (409) — التعديل عبر التصحيحات |
| الإشعارات (Web Push) | مفاتيح VAPID تُولّد على الخادم؛ الاشتراك من «الإشعارات»؛ إرسال مرة واحدة لكل عدد |
| إعادة المحاولة | الإشعار لا يُعلَّم «مُرسَل» إلا عند النجاح؛ الفحص اليومي يعيد المحاولة |
| الفحص اليومي | Vercel Cron مجاني مرتين يوميًا (`vercel.json`): ~07:35 و~22:35 الرياض (دقة ±59 د على Hobby) |
| إيقاف الأتمتة | غرفة التحرير ← العمليات ← «أوقف الأتمتة» |
| السجل | غرفة التحرير ← العمليات: كل نشر/إشعار/فشل/أمان (بلا أسرار أو بيانات شخصية) |

## الإعداد لمرة واحدة بعد النشر
1. احصل على مفتاح خط الإنتاج من **غرفة التحرير ← الأمان ← اعرض المفتاح**.
2. احفظه كـ Network secret في بيئة Claude Code `jeddah-morning` للمضيف `<app>.vercel.app` بالرأس `x-jm-pipeline-key` (لا تلصقه في محادثة).
3. أنشئ المهمتين المجدولتين (صباحية ومسائية) — موجّه المهمة محفوظ في `ops/daily-issue-prompt.md`.

## أتمتة ChatGPT الحالية
**لم تُعدَّل ولم تُربط** ولا يوجد وصول إليها من هذه البيئة. أي ربط مستقبلي يكون بتصدير ملف JSON بصيغة القالب ثم استيراده، وبموافقة مستقلة منك.
