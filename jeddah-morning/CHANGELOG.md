# سجل التغييرات

الصيغة مستوحاة من [Keep a Changelog](https://keepachangelog.com/)، والإصدارات وفق SemVer.

## [0.1.0] — 2026-11-26 — المرحلة الأولى (محلية، غير منشورة)

### أُضيف
- هيكل Next.js 16.4 + TypeScript + Tailwind CSS 4 في مجلد مستقل `jeddah-morning/`.
- الهوية البصرية: أخضر غابي، عاجي، ذهبي هادئ؛ خطوط Amiri وNoto Naskh Arabic وIBM Plex Sans Arabic وPlayfair Display مستضافة ذاتيًا؛ RTL كامل؛ وضع ليلي.
- مخطط محتوى (Zod) للأعداد والمقالات و13 قسمًا، ومستودع محتوى محلي قابل للاستبدال بـ Supabase.
- الصفحات: الرئيسية والغلاف، العدد والفهرس، المقال، قارئ المجلة بتقليب الصفحات، قارئ PDF، الأرشيف، البحث، المفضلة، الإعدادات، صفحة دون اتصال، 404.
- بوابة دخول (`proxy.ts`) بجلسات HMAC وصلاحيتي قارئ ومحرر، ورؤوس `noindex` وأمان.
- غرفة التحرير: محرر الأعداد، النشر الفوري والمجدول، الاستيراد (JSON وPDF مع التحقق من توقيع الملف).
- Service Worker مكتوب يدويًا للقراءة دون إنترنت وحفظ الأعداد، ومعالجات إشعارات غير مفعّلة.
- مخطط Supabase وسياسات RLS (غير مطبّق).
- محتوى تجريبي (5 أعداد) وPDF تجريبي وأيقونات PWA مولدة محليًا.
- 50 اختبار وحدة و21 اختبار طرف لطرف.
- قالب CI لـ GitHub Actions غير مفعّل.

### أُصلح أثناء التطوير
- ‏`::first-letter` (الحرف الأول المكبّر) يكسر اتصال الحروف العربية — استُبدل بفقرة افتتاحية مكبّرة.
- ‏pdf.js كان يرسم العربية مشوهة لأن اتجاه `rtl` يُورَّث إلى `canvas` — ثُبّت `dir="ltr"` على اللوحة.
- أصول pdf.js كانت تمر عبر بوابة الدخول — استُثنيت (ملفات مكتبة عامة بلا محتوى خاص).
