# خطة الاختبارات

## الأوامر
```bash
npm run typecheck && npm run lint && npm test        # وحدات
npm run build && npm run test:e2e                    # طرف لطرف (Playwright، خادم إنتاجي، نسخة مؤقتة من المحتوى)
```

## التغطية الحالية (آخر تشغيل: كلها ناجحة)
| المتطلب | الاختبار | الحالة |
|---|---|---|

| تقليب الصفحات | أزرار، لوحة مفاتيح RTL، سحب، درج الصفحات، الانتقال لصفحة، وضع عمودي، بلا تأثير، حجم النص، التركيز | ✅ |
| PDF | عرض وتنقل؛ رفض ملف غير PDF؛ إرفاق PDF | ✅ |
| دون إنترنت | حفظ العدد ثم قطع الشبكة وقراءة المقال والقارئ؛ صفحة بديلة لغير المحفوظ | ✅ |
| المفضلة والبحث والمكتبة | مفضلة، مجموعات، سجل، بحث بالهمزات، تصفية بالقسم | ✅ |

| منع تكرار المحتوى | `engine.test`: صفر تكرار في العينة + كشف لغز مكرر ونص منسوخ + استثناء المتابعة | ✅ |
| اختلاف التصميم بين الأعداد | لا غلاف/لوحة مكررة متتالية، جِدّة ≥ 85، تدوير كل القوالب، حتمية، تجميد، تجاوز المحرر | ✅ |
